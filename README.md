# 2048 Telegram Mini App

A lightweight 2048-style game built as a Telegram Mini App.

## Features

- 2048-style game mechanics
- Save and load game state
- Share functionality
- Audio support
- Admin panel
- Telegram Mini App integration
- GitHub Pages deployment

- Telegram Mini Apps
